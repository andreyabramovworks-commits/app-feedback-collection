# Технологии простыми словами

- **PostgreSQL** — надёжная база на сервере: проекты, сообщения, задачи и точные цифры для графиков.
- **ECharts** — рисует интерактивные графики прямо в приложении; нажатие на график открывает карточки.
- **OpenTelemetry + Prometheus + Grafana** — технические счётчики и экран здоровья для администратора: сервер жив, есть ли ошибки, насколько быстро отвечает приложение.
- **Loki** — журнал ошибок, если на сервере хватает ресурсов.

## Docker

Сразу разворачиваем приложение через **Docker Compose** в отдельном наборе контейнеров на вашем сервере. Оно не смешивается с уже работающими сервисами: свои контейнеры, сеть, переменные окружения, база/backup‑задачи и обновления.

Elasticsearch, Kibana и Logstash не нужны в MVP: при 60 пользователях они добавят обслуживание без заметной пользы. Вернёмся к ним только если обычного поиска по карточкам станет недостаточно или логов станет очень много.
