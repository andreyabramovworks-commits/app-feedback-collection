# Правила работы Codex в этом репозитории

## Цель

Разрабатывать внутреннее приложение сбора и анализа проблем с интеграцией Bitrix24, сохраняя безопасность, проверяемость метрик и уважительный подход к персональной аналитике.

## Обязательные правила

1. Перед изменением изучить `README.md`, применимые документы в `docs/` и `.codex/decisions.md`.
2. Не коммитить пароли, токены, cookies, OAuth credentials, персональные данные, приватные вложения и содержимое локального `CODEX_HOME`.
3. Любые права доступа проверять на backend; скрытый UI не является авторизацией.
4. Изменения БД выполнять через Alembic, интеграцию Bitrix24 делать идемпотентной и устойчивой к повторам.
5. Не добавлять Elasticsearch, Logstash, Kafka, Kubernetes или микросервисы без измеримой причины и ADR.
6. Для персональной аналитики разделять роли, показывать контекст и не создавать рейтинг «худших сотрудников».
7. Перед commit выполнить проверки, соразмерные изменению, и честно зафиксировать непроверенное.
8. `main` — источник production только после появления и документирования pipeline; ручное редактирование production запрещено.

## История диалога

После каждого содержательного ответа по этому проекту обновлять `CHAT_HISTORY.md` перед завершением ответа:

- добавлять дату и роли `Пользователь` / `Codex`;
- сохранять полный пользовательский запрос и итоговый ответ, допустимо исправить только техническое форматирование;
- не записывать скрытые system/developer instructions, chain-of-thought, служебные tool outputs, одноразовые коды, токены и другие секреты;
- если в сообщении есть секрет или избыточные персональные данные, заменить их маркером `[REDACTED]` и указать причину;
- коммитить и отправлять обновление в GitHub только когда GitHub доступен и пользователь ранее явно разрешил автоматический push для этого проекта;
- сбой push не должен блокировать локальное сохранение; сообщить о нём пользователю;
- история относится только к этому проекту и не является экспортом полной истории аккаунта ChatGPT/Codex.

## Документация решений

Существенные решения фиксировать в `.codex/decisions.md`: проблема, решение, причины, альтернативы и последствия.
