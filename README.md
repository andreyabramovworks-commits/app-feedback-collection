# Пульс проектов

Внутреннее локальное приложение Bitrix24 для обязательной обратной связи по проектам, разбора проблем ОКК, постановки задач и прозрачной аналитики.

> Статус: документация MVP‑пилота на одном проекте. Код ещё не создан.

## Что делает MVP

- показывает сотруднику проекты, по которым он обязан сдать обратную связь;
- принимает отдельные проблемы и идеи, а не длинный список через запятую;
- поддерживает анонимность по умолчанию;
- даёт ОКК удобную ПК‑админку: сортировка, фильтры, карточки, ручное объединение дублей;
- позволяет создать из разбора настоящую задачу Bitrix24;
- показывает дашборды компании, проекта и сотрудника;
- готовит интерфейс со всеми вкладками: рабочие вкладки MVP и честные вкладки‑анонсы будущих релизов с описанием назначения и визуальным концептом.

## Роли в приложении

- **Сотрудник** — создаёт сообщения, дополняет свои записи и видит разрешённую аналитику.
- **Руководитель** — читает данные, комментирует и рассматривает споры по оргструктуре; не является отдельной ролью «руководитель проекта».
- **ОКК** — создаёт проблемы по контрольным точкам, проводит разбор, объединяет дубли и проверяет результат.
- **Администратор** — имеет функции всех ролей, управляет справочниками, ролями, видимостью и интеграциями; только он видит автора анонимной записи и может отменить окончательное назначение ответственности.

Исполнитель задачи не является ролью приложения: исполнение, сроки, наблюдатели и статус задачи ведутся в Bitrix24.

## Технологии

React + TypeScript + FastAPI + PostgreSQL, Docker Compose в отдельном контейнерном наборе на вашем сервере. Для графиков — ECharts; для технического здоровья — OpenTelemetry, Prometheus, Grafana и при наличии ресурсов Loki.
